# 📷 Gasto na Foto

Aplicação web desenvolvida para facilitar a leitura e organização de comprovantes de compras.

O usuário envia uma foto do comprovante e a inteligência artificial analisa a imagem, identificando os produtos e o valor total da compra.

## 🚀 Funcionalidades

- 📷 Envio de foto do comprovante
- 🤖 Leitura do comprovante utilizando IA
- 🛒 Identificação dos produtos
- 💰 Identificação do valor total
- ➕ Soma dos valores de vários comprovantes
- 📊 Contador de comprovantes lidos
- 🧾 Exibição de cada comprovante em um bloco separado
- 🟢 Destaque no valor total

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Puter AI
